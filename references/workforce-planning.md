# 编制、预算与人力成本分析

目标是把业务计划转换为可复核的人员需求与成本情景，而不是从历史人数自动推断“该招几人”。区分已批准编制、实际在岗、计划招聘、替补招聘与项目临时需求。

## 输入与口径

确认规划期间、组织层级、业务量/目标、现有岗位与岗位等级、期初/期末在岗人数、批准编制、预计入离职、预计调岗、工资与奖金方案、社保公积金城市、外包/派遣口径、预算科目与批准人。缺失的薪酬费率、增长率或离职假设必须由用户提供或经授权设为显式情景参数，不填充虚构数字。

稳定键建议为 `期间 + 成本中心 + 部门ID + 岗位ID + 用工类型`。员工明细只用于授权计算，管理层展示优先使用汇总与必要的匿名化视图。合并组织、岗位改名和跨部门调动需保留映射，避免同比口径漂移。

## 核心计算

- `期末在岗 = 期初在岗 + 入职 - 离职 + 净调入`；跨部门调动在全公司汇总时净额应为 0。
- `编制缺口 = 已批准编制 - 实际在岗`。缺口不自动等于招聘需求；还需考虑业务量、效率、替补与预算审批。
- `平均在岗人数 = (期初在岗 + 期末在岗) / 2` 可作简化统计；若有逐日/月数据，按统计口径计算更准确的平均值。明确采用哪一种。
- `期间离职率 = 期间离职人数 / 期间平均在岗人数`，分母为 0 时显示“不适用”，并定义是否排除实习、劳务派遣等群体。
- `人力总成本 = 固定薪酬 + 浮动薪酬 + 企业社保公积金 + 福利/招聘/培训等已纳入科目`。防止同一项目既在工资表又在费用表重复计入；个人扣款不属于企业新增成本。
- `预算差异 = 实际成本 - 批准预算`，同时显示金额与百分比；无批准预算时不生成“节超”判断。

多城市社保公积金与个税核算须转用现有 [薪酬模板规则](payroll-template.md) 并核验政策期间；本参考不提供默认费率。

## 工作流与交付

1. 建立基线：来源、期间、组织/岗位映射、批准编制和预算版本。
2. 生成需求方案：说明业务驱动、岗位职责、必需开始日期、可替代方案与审批人。
3. 做至少“基准 + 用户要求的变化情景”对比；情景假设和成本公式分区保存，不把假设当实际。
4. 输出 `编制计划`、`招聘需求`、`人力成本预算`、`实际与预算差异`、`情景比较` 和简短决策摘要；仅生成任务需要的工作表。
5. 核对人数勾稽、部门调动净额、跨表成本一致性、预算版本、缺失费率与异常值。报告解释“可能原因”时标注证据；不能从单个指标直接认定管理问题。

需要实际 Excel 时读取 [表格规格](workbook-specs.md)。可按用户要求按月、季度或年度复盘；创建定时任务前另读 [自动化规则](automations.md)。
