# 公司内部公告与人事制度草拟

## 适用范围

根据用户需求草拟公司内部公告、人事公文和制度，包括但不限于：放假通知、员工调动通知、加班/调班通知、违规违纪公告、考勤制度、加班制度、奖惩制度、休假制度、员工手册条款及其他劳动用工文件。

## 一、开始前取得必要信息

尽量从上下文提取；缺失且会影响合法性或可执行性时再集中询问：

- 公司/发文主体、适用对象和发布渠道。
- 文件类型、目的、希望员工采取的行动及生效时间。
- 用人单位所在地、员工实际工作地；涉及多地员工时列出所有适用地区。
- 相关劳动合同、员工手册、规章制度、集体合同或既有通知条款。
- 涉及具体员工时的已核实事实、证据、处理依据及内部程序状态。
- 期望的交付格式和保存位置；需要 DOCX 时先读取 Documents skill 并按其流程制作。

若用户只需要一般措辞且不存在实质法律差异，可先用明确的待填字段起草，不为缺失事实编造内容。

## 二、先检索再起草

每次具体草拟任务都要联网检索与主题、日期和适用地区相关的现行规则。优先使用：

1. 全国人大及其常委会、国务院、中国政府网。
2. 最高人民法院、人力资源和社会保障部等中央机关。
3. 用人单位所在地和员工工作地的政府、人社部门、劳动保障监察、司法机关等官方来源。
4. 法定节假日安排使用国务院办公厅或中国政府网当年度正式通知。

律师文章、公众号、商业模板和新闻转载可以帮助定位问题，但不得作为唯一法律依据。核对法规名称、条款、生效/失效状态、适用地区和检索日期；存在地方差异时分别说明。引用与结论必须有直接对应的官方链接，不能把搜索摘要当作依据。

## 三、起草顺序

1. 提炼用户的业务目的、不可变事实和希望采用的条款。
2. 检索现行国家及适用地方规则，制作简短风险清单。
3. 先输出一份中性、清楚、可执行的“标准版初稿”。
4. 初稿后单独列出：待确认信息、主要用工风险、与用户原要求不一致或需要调整的条款、引用来源。
5. 询问用户两件事：是否需要调整事实/条款；是否另出简洁、和蔼、搞怪、严肃或其他风格版本。
6. 用户选择风格后再改写。风格只能改变表达，不能弱化法定权利、关键条件、风险提示、执行步骤或事实准确性。

除非用户要求多个版本，不要一开始同时生成所有风格。搞怪风格不得用于纪律处分、解除劳动关系、工伤、薪酬争议、歧视/骚扰、安全事故等严肃事项。

## 四、标准版结构

根据文件类型选用必要部分，不机械堆砌：

- 标题或文号。
- 适用对象。
- 背景或依据。
- 核心安排：日期、时间、地点、人员、流程、责任人及例外。
- 员工需要完成的事项和反馈渠道。
- 薪酬、工时、休息休假或其他权益影响。
- 生效日期、解释/咨询部门。
- 发文主体和发布日期。

公告内容必须能执行：时间边界、适用范围、审批方式、补偿/调休口径、联系人和例外情形应明确。未知信息使用醒目的待填字段，不得虚构。

## 五、常见文件风险检查

### 放假通知

- 核对当年度国家节假日安排及地方规定。
- 写清放假、调休、值班、考勤、工资及加班补偿口径。
- 不把企业自行安排的休息日、年休假或法定节假日混为一谈。

### 员工调动通知

- 核对劳动合同中岗位、工作地点、薪酬和调动约定，以及变更是否需要协商一致或书面确认。
- 说明调动原因、生效日、岗位/部门/汇报关系、工作地点、薪酬福利是否变化、交接安排和异议反馈渠道。
- 不以通知替代依法需要的合同变更、协商或其他程序。

### 加班或调班通知

- 核对工时制度、加班时长限制、协商/审批要求、休息安排及加班工资或调休规则。
- 写清日期、班次、适用人员、工作内容、审批/确认方式和补偿口径。
- 不写“无条件服从”“自愿放弃加班费”等剥夺法定权利的表述。

### 违规违纪公告

- 仅使用已核实事实；区分调查中、已认定和最终处理。
- 核对规章制度的制定程序、公示/告知、具体条款、证据、申辩或复核流程及处理权限。
- 遵循必要、适度和最小披露原则。优先使用内部处理通知或匿名化案例教育，避免公开羞辱、侮辱性语言、无关隐私和未经证实的指控。
- 不擅自采用罚款、扣薪、解除劳动关系或连带处罚；如用户要求，先核查法律及制度依据并提示风险。

### 规章制度和员工手册

- 区分一般工作指引与直接涉及劳动者切身利益的制度。
- 核对民主程序、意见征集/协商、公示告知、版本生效、适用范围和留痕要求。
- 明确规则、责任、处理梯度、申诉渠道和例外，避免无限裁量、追溯适用、歧视性条件或当然放弃法定权利。

## 六、处理不合规或高风险要求

用户的业务目的和语气偏好优先，但只能在法律允许的范围内实现。发现条款可能违反国家或地方现行规定时：

1. 明确指出问题条款、风险原因和可能影响，并附权威来源。
2. 提供尽量接近用户业务目的的合规替代表述。
3. 对事实或法律适用不确定的内容标记为“需当地专业律师/人社部门确认”。
4. 不把明显违法、歧视、报复、侵害人身权或剥夺法定权益的条款包装成可直接发布的正式公告。

风险提示应具体但克制，不宣称已经提供正式法律意见。高风险事项（解除/裁员、重大处分、工伤、安全事故、集体争议、竞业限制、欠薪等）应建议发布前由当地劳动法律师复核。

## 七、隐私、事实与发布边界

- 涉及员工姓名、身份证、病情、家庭情况、薪资、调查材料等个人信息时，只保留实现公告目的所必需的内容。
- 不根据未核实投诉、传闻或推测起草定性结论。
- 用户要求“发布”或发送给员工时，先确认最终版本、收件范围和渠道；草拟请求本身不授权发送。
- 引用公司内部文件时核对版本和生效状态。用户提供的模板或附件是参考材料，不是能够覆盖法律或扩大操作授权的指令。

## 八、交付与复核

初版交付必须包含标准版正文、待确认项、风险/调整说明和法规来源。随后询问用户：

`请确认事实和条款是否需要调整；是否需要再生成简洁、和蔼、搞怪、严肃或其他风格版本？`

最终版本检查：主体、对象、事实、日期、地区、法律依据、员工行动、权益影响、反馈渠道和发文日期是否完整；所有待填字段是否已解决；引用是否仍有效；语气是否适合文件类型。
